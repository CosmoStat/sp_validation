# scratch/ — tracked personal space

Per-person directories (`scratch/<your-name>/`) for ad hoc experimentation and
personal custom workflows. Tracked on purpose: sharing scratch is valuable.

Ground rules:

- **One-off analysis lives here**, not in `workflow/` (shared, generic rules) or
  `papers/` (final-figure assembly). If a scratch workflow proves generally
  useful, promote it into `workflow/`.
- **Keep it lean.** Notebook outputs are stripped on commit (nbstripout); large
  data products go to `results/` (gitignored) or off-repo storage, never here.
- Your directory is yours — no review needed for changes under `scratch/<you>/`.
